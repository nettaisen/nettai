# Nettai Slot Codes

The Battle Network games' chip codes as an outline font: the slots' chip codes (6 by 5 pixels, under each chip's icon), A to Z and '*', traced from their pixels with sharp
corners for the enhanced mode (the user: "you should trace ABCDEFGHIJKLMNOPQRSTUVWXYZ* for the chip codes font like
you did digits: you should make a font for both the big chip code displayed in the chip window and the little chip
code displayed under the chip icon"). A, V, X, Y, Q, the asterisk (and the big S, the small G and J) are drawn whole from their
pixels. A glyph pixel is 100 units, each glyph in an 8-pixel cell (advance 800).

Built by bn6battle-verify's `tools/digits/build_codes_otf.py` from EXE6's pack (EXE5's codes are the same; EXE4's
own few are left out).
