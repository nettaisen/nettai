# Nettai Banner Digits

The Battle Network games' banner digits (the numbered banners, 6 by 14 pixels) as an outline font, for the enhanced
mode's banners. Another drawing from Nettai Digits' (an unslashed 0, the 1 a flagged bar, a flat-topped 6, a 7 without
walls), so a family of its own; digits alone. Traced from their pixels with sharp corners; a glyph pixel is 100 units
(the digits 1400 tall, the same stroke weight as Nettai Digits'), each glyph in the game's 8-pixel cell (advance 800,
the face from 100).

Built by nettai-verify's `tools/digits/build_otf.py` from EXE6's pack (EXE5's banner digits are the same; EXE4's
are another drawing again, left out).
